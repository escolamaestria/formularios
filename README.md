# formularios

Formulários de diagnóstico dos **Maestros do Direito**, publicados via GitHub Pages para que o
cliente abra o link em qualquer navegador, sem conta e sem login.

| Página | Link |
|---|---|
| Diagnóstico inicial da serventia (mentoria cartório) | https://escolamaestria.github.io/formularios/canaa/ |

Páginas são estáticas: não coletam nem armazenam nada. Quem responde devolve as respostas pelo
botão de WhatsApp, por cópia ou em PDF. Fonte de verdade de cada formulário fica no repositório
privado do OS; aqui vai só a cópia publicada.
